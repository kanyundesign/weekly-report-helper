# 周报助手项目复盘

> 一次设计师使用 Cursor + AI 完成全栈开发的实践记录

---

## 一、项目背景

### 痛点

设计团队每周需要手动整理周报，流程繁琐：
1. 从 Notion 任务看板逐个复制任务进展
2. 手动组织语言、格式化内容
3. 粘贴到周报文档，重复 N 次

**核心问题**：信息已存在于 Notion，却需要人工搬运和加工。

### 解决方案

构建自动化工具链：

```
Notion 任务数据 → AI 内容生成 → 自动写入周报页面
```

**技术选型**：
- **Next.js**：前后端一体，API Routes 处理业务逻辑
- **Notion API**：数据读写
- **Claude AI (Bedrock)**：内容理解与生成
- **Vercel**：零配置部署

---

## 二、核心功能

| 功能 | 说明 |
|------|------|
| 📋 任务抓取 | 按成员、日期自动筛选本周任务 |
| 🤖 AI 生成 | 结构化周报：上周进展 / 本周计划 / 信息同步 |

| 🏖️ 请假管理 | 管理模式下标记请假成员 |
| ⚡ 一键生成 | 批量生成全员周报 |

## 三、关键技术挑战与解法

### 1. Notion API 的"坑"

**问题**：API 返回结构复杂，属性名可能被用户修改。

**解法**：动态获取数据库 schema，不硬编码属性名：
```typescript
const titleProperty = Object.entries(database.properties)
  .find(([_, v]) => v.type === 'title')?.[0];
```

**问题**：`heading_2` 不支持嵌套 children。

**解法**：改用 `after` 参数在标题后追加 block，而非嵌套。

---

### 2. Serverless 架构的限制

**问题**：Vercel 文件系统只读，无法持久化 `submissions.json`。

**解法**：内存存储 + 前端传参。

```typescript
// 内存存储（单次请求生命周期内有效）
export const globalStore = { submissions: {}, leaves: {} };

// 关键数据由前端传入，而非读取服务端状态
POST /api/admin/sync-leave
Body: { leaveMembers: ['member1', 'member2'] }
```

**认知升级**：Serverless ≠ 传统服务器，每个请求可能是全新实例。

---

### 3. AI 输出的不确定性

**问题**：让 AI 生成进度条 `████░░`，结果不稳定。

**解法**：**后端预计算，AI 只负责"填空"**。

```typescript
// 后端生成确定性内容
const progressBar = generateProgressBar(progress); // ████████░░ 80%
const warning = isOverdue ? '🔴 已延期3天' : '';

// Prompt 明确指示：直接复制，不要修改
`任务进度条和预警信息已预先计算，请原样保留：${progressBar} ${warning}`
```

**原则**：AI 擅长理解和生成，不擅长精确计算。把确定性工作留给代码。

## 四、设计师视角：Cursor 使用心得

### 1. 角色转变

从「提需求方」变成「对话式开发者」：
- 不需要记忆语法细节
- 需要清晰描述**意图**和**预期结果**
- 需要判断生成代码的**合理性**

### 2. 高效协作模式

| ✅ 有效做法 | ❌ 低效做法 |
|------------|------------|
| 一次专注一个功能点 | 一次提 5 个需求 |
| 提供截图说明预期效果 | 纯文字描述 UI |
| 遇到报错贴完整日志 | 只说"报错了" |
| 理解后再继续 | 盲目接受所有改动 |

### 3. 核心认知

> **Cursor 是放大器，不是替代品。**

- 放大你的想法落地速度
- 放大你的问题排查效率
- 但不能替代：需求判断、架构设计、技术选型

设计师优势：对用户体验敏感，能快速判断"这样做对不对"。

## 五、遇到的问题清单

| 问题 | 原因 | 解法 |
|------|------|------|
| `Could not find property: Name` | Notion 属性名被修改 | 动态获取 schema |
| `annotations should be not present` | API 结构不符合规范 | 调整 block 格式 |
| `Block does not support children` | heading 不支持嵌套 | 改用 after 参数 |
| GitHub Pages 404 | 静态托管不支持 API | 迁移到 Vercel |
| Vercel 请假功能失效 | 只读文件系统 | 内存存储 |
| "0人更新" | Serverless 内存隔离 | 前端传参 |
| AI 进度条不准 | AI 不擅长精确计算 | 后端预生成 |
